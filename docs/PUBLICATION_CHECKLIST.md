# Publication gate

- [ ] Confirm entitlement to publish the analytical narrative without sharing confidential original source proposals.
- [ ] Confirm any organisational affiliation and authorship descriptions are strictly accurate.
- [ ] Check all input CSVs contain only **explicitly illustrative** or consent-cleared, non-sensitive data.
- [ ] Execute automated model tests and inspect reproducibility logs.
- [ ] Check every figure and output against the input provenance table.
- [ ] Verify latest applicable programme/methodology/legislation before making current compliance statements.
- [ ] Avoid presenting scenarios as measured emissions, credited tonnes, completed events or regulatory approvals.
- [ ] Decide the intended software licence and dataset permissions; no default open licence is implied.
