# Data dictionary

All files in `data/illustrative` are programmatically constructed **illustrative scenario inputs**; they do not contain field measurements. `data/templates` is the author-editable schema for future research and may have blank rows. The `assumption_origin` or `data_status` field must be retained when entering new cases. Physical quantity units must be stated in the CSV column header or this document. The analysis code validates required columns and disallows silent replacement of missing empirical inputs.

The repository also provides `docs/EVIDENCE_CROSSWALK.csv` with provenance/status fields; it is not an empirical dataset or a substitute for source permission.
