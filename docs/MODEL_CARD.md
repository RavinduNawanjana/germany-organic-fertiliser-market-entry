# Model card

|---|---|
| Purpose | Route-specific PFC/CMC evidence register, unit economics, landed-cost sensitivity and decision gates |
| Type | Transparent screening / analytic demonstration |

| Required human review | Sector specialist, data owner, relevant regulatory/verification authority |
